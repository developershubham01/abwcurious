# abwcurious

> **Engineering a Better Future** — AI, Technology, Education, and Innovation.

ABWcurious is an IT and technology solutions company delivering intelligent digital solutions, future-ready education, cybersecurity, software engineering, IT services, and talent solutions. Headquartered in Nerul, Navi Mumbai, India.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Carbon Design System aesthetic
- **State & UI**: Radix UI, Lucide Icons, Framer Motion

## Getting Started

First, install dependencies:
```bash
npm install
```

Then run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production
```bash
npm run build
npm run start
```
